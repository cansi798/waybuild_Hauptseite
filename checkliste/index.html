Launch-Checkliste

19 von 31 Punkten offen.Diese Übersicht ist nur in der Vorschau erreichbar und wird vor dem Livegang entfernt. Sobald ein Wert in der Konfiguration eingetragen ist, verschwindet der zugehörige Hinweis automatisch.

Pflicht vor dem Start (10)

  • Registergericht

    Steht im Handelsregisterauszug, z. B. „Amtsgericht München“.

    Nachtragen in: src/config/site.ts → company.registerCourt

  • Handelsregisternummer (HRB)

    Steht im Handelsregisterauszug.

    Nachtragen in: src/config/site.ts → company.registerNumber

  • Umsatzsteuer-ID

    Kommt vom Bundeszentralamt für Steuern. Falls noch nicht vorhanden: Zeile im Impressum vorerst entfernen.

    Nachtragen in: src/config/site.ts → company.vatId

  • Server-Hoster (Name & Anschrift)

    Pflichtangabe in der Datenschutzerklärung, sobald die Website auf dem eigenen Server liegt.

    Nachtragen in: src/config/site.ts → company.hoster

  • Domain & Server bereitstellen, Website hochladen

    GitHub Pages ist nur die Vorschau. Live-Build lokal erzeugen (npm run build) und den Inhalt von dist/ per SFTP/FTP auf den Server laden – Anleitung in der README.

    Nachtragen in: README.md → „Live gehen (eigener Server)“

  • E-Mail-Postfach kontakt@waybuild.de einrichten

    Die Adresse steht überall auf der Website – sie muss vor dem Start funktionieren.

    Nachtragen in: Beim E-Mail-/Domain-Anbieter

  • AGB anwaltlich prüfen lassen

    Die AGB-Seite ist eine Vorlage für das Abo-Modell. Ohne geprüfte AGB keine Abo-Verträge abschließen.

    Nachtragen in: src/pages/agb.astro

  • Datenschutzerklärung prüfen lassen

    Web3Forms und WhatsApp sind jetzt beschrieben (Oktober 2026). Vor dem Start prüfen lassen: Anbieterangaben/AV-Vertrag Web3Forms und Abschnitt Hosting nach Umzug auf den eigenen Server.

    Nachtragen in: src/pages/datenschutz.astro

  • Leistungsbeschreibungen für Abos (SLA, Fair Use, Speicher)

    Für IT-Betreuung, Nextcloud-Hosting und Software-Pflege je eine kurze Leistungsbeschreibung als Anlage zum Angebot erstellen – inkl. AV-Vertrag (Art. 28 DSGVO) für Nextcloud und IT.

    Nachtragen in: Eigenes Dokument, Verweis in src/pages/agb.astro § 2a

  • Hinweise ausblenden

    Wenn alles erledigt ist: SHOW_HINTS auf false setzen. Dann verschwinden alle gelben Hinweise.

    Nachtragen in: src/config/site.ts → SHOW_HINTS

Wichtig (6)

  • Telefonnummer (aktuell erfundener Platzhalter 0151 00000000)

    Echte Nummer eintragen und PHONE_IS_PLACEHOLDER auf false setzen – die Nummer steht in Header, Footer, WhatsApp-Links und Kontakt.

    Nachtragen in: src/config/site.ts → company.phone

  • Kontaktformular aktivieren (Web3Forms)

    Auf web3forms.com mit kontakt@waybuild.de einen kostenlosen Access-Key holen und in GitHub als Variable WEB3FORMS_KEY speichern. Danach kommen Anfragen direkt per E-Mail an.

    Nachtragen in: GitHub → Settings → Secrets and variables → Actions → Variables

  • SLA-Wert für kleine Änderungen eintragen

    Auf der Startseite ist die Bearbeitungszeit für kleine Änderungen noch als Platzhalter markiert („[Wert einsetzen]“). Wert von Jamil/Can eintragen – dann verschwindet die Markierung.

    Nachtragen in: src/config/hauptseite.ts → SLA_KERN

  • Leistungsversprechen absichern

    „Live in 14 Tagen“, „Sprachgesteuerte Änderungen“, „KI-gestützte Erstellung“, die Service-Versprechen (u. a. „kleine Änderungen oft in Minuten online“, „Antwort spätestens am nächsten Werktag“) und die selbstoptimierende „Intelligente Website“ stehen auf der Website. Für die Auswertung von Besucherdaten Datenschutzerklärung/Einwilligung prüfen. Prozesse und Werkzeuge so aufsetzen, dass das eingehalten wird.

    Nachtragen in: src/config/site.ts → INKLUSIVE, faqs

  • Rechnungsvorlage: Bankverbindung (IBAN) & Steuernummer

    Für die ersten Abo-Rechnungen: IBAN, Steuernummer bzw. USt-ID auf Rechnung und im Angebot. Nicht auf der Website nötig.

    Nachtragen in: Buchhaltung / Rechnungsprogramm

  • Foto und Kurzvorstellung der Gründer

    Menschen kaufen von Menschen – ein echtes Foto auf „Über uns“ erhöht die Anfragen deutlich.

    Nachtragen in: src/pages/index.astro → Abschnitt „Über waybuild IT“ (#ueber)

Später (3)

  • Erste Referenzprojekte

    Sobald die ersten Kunden live sind (mit deren Freigabe) eintragen. Keine erfundenen Referenzen oder Bewertungen!

    Nachtragen in: src/config/site.ts → references

  • Google Search Console & Unternehmensprofil

    Nach Domain-Umzug Sitemap einreichen und Google-Unternehmensprofil für lokales SEO anlegen.

    Nachtragen in: search.google.com/search-console

  • Social-Profile & Google-Unternehmensprofil verknüpfen

    Links in company.sameAs eintragen – Google verbindet dann Website und Profile zu einer Marke.

    Nachtragen in: src/config/site.ts → company.sameAs

Erledigt (12)

  • Name der Geschäftsführung

    Pflichtangabe im Impressum und in jeder geschäftlichen E-Mail.

  • Straße & Hausnummer

    Ladungsfähige Anschrift – Pflicht im Impressum (§ 5 DDG).

  • Postleitzahl

    Teil der Anschrift im Impressum.

  • Ort

    Teil der Anschrift im Impressum.

  • Website entwickelt & online

    Alle Seiten mobil & Desktop, Deployment: Build lokal, dist auf main (GitHub Pages).

  • SEO-Grundlagen

    Meta-Daten, strukturierte Daten (JSON-LD), Sitemap, Lighthouse SEO 100.

  • Favicon & Social-Media-Vorschau

    Icons für Browser, iPhone, Android sowie Vorschaubild für WhatsApp/LinkedIn.

  • CI-Handbuch

    Logo, Farben, Schriften, Tonalität, Visitenkarte, E-Mail-Signatur – nur intern als PDF.

  • Monatspreise für Website as a Service festlegen

    Festgelegt von Jamil am 19.10.2026: 79 € / Monat und 139 € / Monat (intelligente Website), netto.

  • AGB an Website as a Service anpassen

    Am 25.10.2026 an das aktuelle Modell angepasst: zwei Varianten (79 € / 139 € netto im Monat), keine Einrichtungskosten, 24 Monate Laufzeit, Website/Code/Domain gehören dem Kunden. Offen bleibt allein die anwaltliche Prüfung (eigener Punkt).

  • Firmensitz / Einzugsgebiet für lokales SEO

    Adresse Norderstedt ist eingetragen – die Seite meldet waybuild jetzt als lokales Unternehmen (ProfessionalService) an Google. Optional später: Stadt in Titel & Texte aufnehmen („IT-Service Norderstedt“).

  • Finales Logo (optional)

    Das waybuild-IT-Logo ist eingebaut (Header, Footer, Icons, Vorschaubild). Für noch schärfere Darstellung später eine SVG-Fassung vom Designer einsetzen.
